ติดตั้ง Inventory Intelligence
บนบัญชี Google ของคุณ

ระบบจัดการสต็อกสำหรับเจ้าของกิจการหนึ่งบัญชี ฐานข้อมูลอยู่ใน Google Sheets ของคุณ ใช้อินเทอร์เน็ตและบัญชี Google ที่อนุญาต Apps Script

เปิด Index.html บนเครื่องเป็นโหมดตัวอย่าง ข้อมูลในโหมดนี้หายเมื่อรีเฟรช ต้อง deploy ตามขั้นตอนด้านล่างเพื่อบันทึกข้อมูลจริง

1. สร้างฐานข้อมูลของคุณ

เปิด Google Sheets ใหม่ ตั้งชื่อ Inventory Intelligence แล้วเลือก Extensions → Apps Script

2. วางไฟล์ระบบ

  1. แทนที่เนื้อหา Code.gs ด้วยไฟล์ Code.js ในแพ็กเกจ
  2. กด + → HTML ตั้งชื่อ Index แล้ววางเนื้อหา Index.html
  3. ใน Project Settings เปิด Show appsscript.json manifest file แล้วแทนที่ด้วย appsscript.json จากแพ็กเกจ เขตเวลาต้องเป็น Asia/Bangkok
  4. กด Save ตรวจว่ามี Code.gs, Index.html, appsscript.json ไม่ต้องนำโฟลเดอร์ video หรือไฟล์ทดสอบไปวาง

3. เริ่มระบบและให้สิทธิ์

เลือกฟังก์ชัน setupEmpty แล้วกด Run ยืนยันสิทธิ์บนบัญชี Google ของคุณ ระบบจะสร้าง Products, Transactions, Alerts, PurchaseOrders และ Settings กลับไปตรวจชีตที่สร้าง หากองค์กรบล็อก Apps Script ให้ติดต่อผู้ดูแลระบบ

4. เผยแพร่ Web app

กด Deploy → New deployment → Web app เลือก Execute as: Me และ Who has access: Only myself จากนั้น Deploy และคัดลอก URL ที่ลงท้าย /exec เปิดด้วยบัญชีเจ้าของเดียวกัน

การติดตั้งนี้รองรับเจ้าของบัญชีเดียว อย่าเปิดสิทธิ์ Anyone เพราะแอปทำงานด้วยสิทธิ์เจ้าของฐานข้อมูล หากต้องการหลายผู้ใช้ต้องออกแบบสิทธิ์และตรวจสอบตัวตนเพิ่มเติม

5. ตั้งค่าและตรวจยอด

  1. เพิ่มสินค้าใหม่ ระบุ SKU เช่น DEMO-01 ต้นทุน 10 และยอดตั้งต้น 10
  2. รับเข้า 5 หน่วย แล้วเบิกออก 3 หน่วย ยอดคงเหลือต้องเป็น 12
  3. ลองเบิก 13 หน่วย ระบบต้องปฏิเสธ และยอดยังเป็น 12
  4. สร้าง PO จากแผนสั่งซื้อ รับสินค้าเพียงครั้งเดียว ตรวจยอดและประวัติใน Sheets
  5. ตั้งชื่อบริษัทและอีเมล ลองตรวจสต็อก แล้วติดตั้ง Trigger หากต้องการอีเมล/รายงานอัตโนมัติ เวลา Trigger เป็นช่วงเวลาประมาณตาม Google

โหลดข้อมูลตัวอย่างได้เมื่อฐานข้อมูลว่างเท่านั้น หากต้องการทดลองให้ใช้ Sheets และ Apps Script ชุดใหม่แยกจากข้อมูลจริง

6. สำรองข้อมูลและอัปเดต

ก่อนอัปเดตให้ทำสำเนา Google Sheets และบันทึก version ของ deployment เดิม วาง Code.js และ Index.html รุ่นใหม่โดยไม่ลบชีต จากนั้น Deploy → Manage deployments → Edit → New version → Deploy ใช้ URL /exec เดิม ตรวจยอดอีกครั้ง หากเกิดปัญหาให้เลือก version ก่อนหน้า

แก้ปัญหาที่พบบ่อย

  • เห็นแถบโหมดตัวอย่าง: เปิด URL /exec จาก Apps Script แทนไฟล์ HTML
  • เข้าถึงไม่ได้: เข้าบัญชี Google เจ้าของ ตรวจสิทธิ์ deployment และนโยบายองค์กร
  • กราฟไม่ขึ้น: ตรวจอินเทอร์เน็ตและการเข้าถึง CDN ของ Chart.js
  • รับอีเมลไม่ได้: ตรวจอีเมล การเปิดแจ้งเตือน โฟลเดอร์ Spam และโควตา MailApp
  • ยอดผิด: ตรวจประวัติธุรกรรม ห้ามแก้ยอดคงเหลือในชีตโดยตรง ให้ใช้รายการปรับปรุง

ขอบเขตการใช้งาน

เหมาะกับคลังขนาดเล็กและการติดตั้งแยกต่อองค์กร ไม่ใช่ระบบบัญชีหรือ ERP เต็มรูปแบบ ไม่มีหลายคลัง ไม่มีการนำเข้า CSV ไม่มีการจัดการล็อต/วันหมดอายุ และไม่มีระบบชำระเงินในตัว รายงานย้อนหลังใช้ต้นทุนปัจจุบันประมาณมูลค่าคงคลัง อายุสินค้าเป็นเวลาตั้งแต่รับเข้าครั้งล่าสุด ไม่ใช่อายุของแต่ละล็อต Google มีโควตาและข้อจำกัดเวลาทำงาน
